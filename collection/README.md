# Collection Artwork — horror Mama 2

This directory holds the main artwork for the Nuvio collection "horror Mama 2".

## Final filenames

| File | Purpose | Specs |
|---|---|---|
| `collection/horrormama-cover.png` | Main portrait cover | PNG, 1000 x 1500 px, 2:3 |
| `collection/horrormama-backdrop.jpg` | Main widescreen backdrop | High-quality JPG, 1920 x 1080 px, 16:9 |

The main collection logo lives separately at `logos/collection/horrormama-logo.png` (transparent PNG, ~1200 px wide).
